## 1. 家底盘点（已核实，2026-07-25 读码/读数据确认）

**结论：这个方案的多数管道已经跑通，缺口只有三块。**

### 1.1 已实现的身份注入（`liulian/models/torch/timellm.py`）

| 模式 | 实现 | 状态 |
|---|---|---|
| `none` | 基线，prompt 与官方逐位一致 | ✅ 已验证（ETTh1@96 MSE 0.3908 与官方一致） |
| `entity_description` | **文本身份**：把每站自然语言描述注入 prompt（`_compose_prompt`/`_resolve_entity_descs`，L381+） | ✅ 已跑 n=3 |
| `embedding` | **数值身份**：`nn.Embedding(num_entities, d_model)` 加到 patch 嵌入之后（L117） | ✅ 已跑 n=3 |
| `random_embedding` | **容量对照**：同上但 `requires_grad_(False)`（L123），0 可学习参数 | ✅ 已跑 n=3 |

harness 支持的模式（`experiments/swiss_river/run_experiment.py:680`）：
`['none', 'entity_description', 'embedding', 'random_embedding']`。

### 1.2 已有结果（swiss-1990，GPT-2，n=3，MSE）

| 模式 | MSE | vs none |
|---|---|---|
| none | 0.01457 ± 0.00022 | — |
| 文本（entity_description） | 0.01430 ± 0.00027 | −1.9%（**不显著**，±3.3% 跨零） |
| **数值（embedding）** | **0.01200 ± 0.00035** | **−17.6%（高度显著，7× std，3/3 seed 一致）** |
| 数值（frozen random，0 可学习） | 0.01178 | −19.2%（≈ 学习版 ⟹ 增益来自**可区分性**，非容量） |

### 1.3 已有数据

- **swiss-1990**：28 个 FOEN 水温站，训练 7 920 天 / 测试 2 188 天。
- **站点文本描述**：28 条真实描述（河名 + 地点 + 经纬度），`configs/entity_descriptions.yaml`。
- 另有 swiss-2010 / swiss-zurich 两个划分。

### 1.4 三个缺口

| 缺口 | 现状 | 接入难度 |
|---|---|---|
| **① 微调对照** | **全部冻结**——`timellm.py:334` 一行 `param.requires_grad = False` 冻掉整个 LLM | **低**：在该处加 `llm_tuning ∈ {frozen, lora, last_k}` 开关；需加 `peft` 依赖（目前无） |
| **② 更多 TS-LLM 骨干** | 只有 Time-LLM（内置 GPT2/LLAMA/BERT 三种主干） | 中：待调研定 2–3 个 |
| **③ 更多水文数据集** | 只有 swiss（28 站） | 中：待调研定 |

## 5. 实验设计骨架（基于已核实家底）

**核心是一张三因子表**，每个因子都已有或易于实现：

| 因子 | 取值 | 现状 |
|---|---|---|
| **身份注入方式** | none / 文本 / 数值嵌入 / 冻结随机 / **坐标** / **文本+数值** | 前四个✅；后两个待加 |
| **LLM 可训性** | **frozen** / **LoRA** / 末 k 层解冻 | 仅 frozen ✅；**这是本轮新重点** |
| **骨干** | Time-LLM(GPT2) / +2 个最新 TS-LLM | 前者✅ |

**为什么"微调×身份"这一格最有价值**：我们已经测到**冻结 LLM 几乎用不上文本身份**（−1.9%，不显著）。
若解冻/LoRA 后文本身份变得有效，则结论从"文本没用"升级为**"文本身份的有效性取决于该通道是否可训练"**
——这是机制性主张，而不是一个 null result。这一格**成本最低、信息量最高**，应优先做。

**预注册的三个预测**（先写下来，避免事后编故事）：

| # | 预测 | 若被推翻说明什么 |
|---|---|---|
| P1 | 冻结时：数值 ≫ 文本（已测，−17.6% vs −1.9%） | — |
| P2 | **LoRA 后文本身份增益显著上升**，与数值差距缩小 | 若不变 ⟹ 瓶颈不在可训性，而在 reprogramming 接口本身，需改查探针 |
| P3 | **文本+数值 > 单独任一**（信息互补） | 若不优于数值单独 ⟹ 文本未提供额外信息 |
