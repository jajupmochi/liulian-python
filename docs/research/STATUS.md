## 术语速查（看表前先扫一眼，不用翻历史）

- **实体标识符 (entity identifier)** = 告诉模型"这条序列是哪个实体/通道/站点"的编码。我们对比 6 种：`none`(不给) / `embedding`(学一个数值向量) / `onehot`(独热) / `sinusoidal`(正弦编码) / `random`(随机向量) / `coordinates`(经纬度坐标)。
- **per-entity（每实体建模）** = 一个共享模型，每个样本自带身份（站点各自一条序列）。
- **multi-channel（多通道）** = 把所有实体当成多个通道一次性喂进去。
- **denorm RMSE（反归一化均方根误差）** = 还原成真实物理单位后的误差，swiss 是 °C；**越低越好**。
- **注入位置 (injection point)** = 身份信息加在模型的哪一层——归一化**之前** vs **之后**。
- **论文主张一（注入-归一化交互）** = 身份必须注入在"每通道归一化"之后，注在之前会被归一化抹掉。
- **论文主张三（增益依赖建模模式）** = 身份增益在 per-entity 模式下大、在 multi-channel 模式下小。

### 2.4 Time-LLM（大模型重编程预测）

| 实验 | 配置 | 结果 | 结论 |
|---|---|---|---|
| 复现验证（我们 vs 官方代码） | ETTh1@96, GPT-2 | 逐 epoch 逐位相同，MSE 0.3908 | ✅ 移植忠实 |
| **ETTh1 文本注入**（entity_description，n=3） | GPT-2 | none 0.39125 / 注入 0.39121 | ❌ **null**（弱实体，跨 seed 符号翻转） |
| **swiss 文本注入**（真实站点描述，n=3） | GPT-2 | none 0.01457 / 注入 0.01430（**−1.9%**） | ⚠ 方向性但**不显著**（±3.3% 跨零） |
| **swiss 嵌入注入**（embedding 数值向量，n=3）★ | GPT-2 | none 0.01457 / 嵌入 **0.01200（−17.6%）** | ✅ **高度显著**（7× std，误差棒不重叠，三 seed 一致 −14.7/−20.5/−17.7%） |
| **swiss 容量对照**（random_embedding 冻结随机向量，0 可学习） | GPT-2 | **0.01178（−19.2%）** | ✅ ≈ 学习版 embedding → 增益是**身份/distinctness**，非可学习容量 |

**核心发现（swiss，n=3，最终）**：对 Time-LLM（冻结 GPT-2 重编程）：
- **数值身份（每站一个可区分向量加到 patch）大幅有效**：learned embedding −17.6%、frozen random −19.2%，**两者相当**（误差棒重叠）、均高度显著（7× std）。
- **文本身份（描述文字）几乎无效**：−1.9%（不显著）；ETTh1 文本 = null。
- **容量对照判定**：frozen random（0 可学习参数）≈ learned embedding → 增益来自**每站可区分性（身份）**，**不是**那 448 个可学习参数的容量（research-critic 疑虑排除）。
- **数值身份是域依赖的（2×2 完整）**：ETTh1（弱实体，1 台变压器 7 个相关通道）上 embedding **+2.3%**、random_embedding **+2.4%**（vs none 0.39125）→ **反而变差**。对比 swiss −17.6%。

**2×2 最终表（MSE，n=3）**：

| 域 | none | 文本身份 | 数值身份(embedding) |
|---|---|---|---|
| swiss（实体丰富，28 河流站） | 0.01457 | 0.01430(−1.9%) | **0.01200(−17.6% ✅)** |
| ETTh1（弱实体，7 相关通道） | 0.39125 | 0.39121(null) | 0.4004(**+2.3% ❌**) |

**最终结论**：数值身份的大幅增益**不是**普适"数值>文本"机制，而是**域依赖**——只在"多个真正可区分的实体"（swiss 28 河流）时有用，弱实体（ETTh1 7 相关通道）反而添噪变差。对冻结 LLM，数值是有效机制、文本不是；但两者都要"实体丰富"前提。印证主矩阵 C3（增益依赖 regime/域）。commits `de02de8`(H2), `9f63171`(容量对照)。
